CSS Astral Shared Assets for CSS v@VERSION@

Ghost materials and animation support for Genessa's customized doubles.

Installation
1. Close Mortal Shell II.
2. Install the separate CSS v@VERSION@ runtime ZIP.
3. Extract CSS_AstralSharedAssets_P into:
   MortalShell2/Content/Paks/~mods/

Keep all three files together: .pak, .utoc and .ucas.
Keep the older CSS_SharedAssets_P package if you have it. That is a separate
Eve animation/skeleton package and is not replaced by this download.

This package does not include outfits, UE4SS or personal settings. Existing
Unholy Genessa, Eve and Commander White outfit packages do not need recooking.

Use MISC > Faithful Doubles or Stray Doubles > Use CSS while playing Genessa.
Default uses the game's original double. Unsupported appearances also fall
back to the original double. NPC/enemy support is partial; some looks may have
visual or animation issues. Wearing Genessa's appearance on another gameplay
shell does not grant her abilities.

To remove this package, close the game and remove CSS_AstralSharedAssets_P.
CSS can still customize the player without it; doubles use their original look.
