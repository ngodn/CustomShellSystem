# 0.3.1 release verification

Scope: the dodge material correction committed in `841f628`, followed by the
version bump and current publication copy. Only CSS is released as 0.3.1.
CSSX, UI Kit and Cheat Menu remain at 0.3.0. Their ABI and the existing outfit
containers are unchanged.

## Live evidence before packaging

The corrected native core was built and staged on Steam build 25265616.
_eins0fx confirmed that the shredded-body trail is gone. One variant from each
of nine installed outfits passed material readback. Color reset and palette
restoration passed. Material and retained-pawn mesh recovery reused the same
materials and passed the existing 100 ms apply budget. These tests do not cover
all variants, every gameplay shell, or an older executable.

The final tagged ZIP has not had a new in-game cold launch. Do not confuse the
live developer-core check with a cold launch of the release artifact.

## Artifact checks

Passed before publication:

- Annotated tag: `v0.3.1`, source commit `3874082b898d2768510db79f0613f6355216e852`.
- Clean detached source checkout. Release build used the pinned UE4SS SDK,
  with `CSS_INVENTORY_DEV=OFF` and `CSS_TRANSITION_TESTS=OFF`.
- 53 Python tests and nine native test groups passed against tagged source.
  The first Python run lacked private converter fixtures; providing the same
  local fixtures used by development resolved those failures, without changing
  tagged source or the ZIP. No tests were skipped in the completed run.
- 352 startup checks passed on a temporary extraction of the final ZIP with
  the installed outfit packages. These cover generated state, persistence,
  backup recovery, package discovery, thumbnails, color resources and cache
  regeneration. Installed user state and game saves were not touched.
- The final archive passed its strict eight-member allowlist, x64 DLL headers,
  core selection, source revision and payload hashes. The built core includes
  the DarkBro displacement correction. The ZIP was reverified after startup
  tests; the SHA-256 sidecar matches.
