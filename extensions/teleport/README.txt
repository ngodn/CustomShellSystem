CSSX Teleport
=============

Teleport to any point on the world map. Open the map, hover a beacon, gate,
dungeon or well, and the Teleport prompt appears. Press T on the keyboard or R3
(click the right stick) on a controller to travel there. The jump uses the
game's own streaming teleport, so there is no loading screen.

Requires CSSX. Install CSSX first, then drop this folder into
Sparta/MortalShell2/Binaries/Win64/ue4ss/Mods/ alongside it.

Settings (CSSX tab > Teleport)
------------------------------
- Map teleport: turn the whole feature on or off.
- Confirmation: ask before teleporting, or jump on the first press.
- Allow locked points: teleport to points you have not unlocked yet. Turn this
  off to show the prompt only where the game already lets you fast travel.
- Departure camera: face the character as the teleport begins, or keep the game
  camera.

Notes
-----
- The world map is untouched when the feature is off.
- Settings are saved to CSSX/state/eins0fx.teleport.json.
