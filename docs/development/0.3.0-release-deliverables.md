Agreed with _eins0fx on 15 September 2026. Finish feature parity and verification before bumping versions or preparing release archives.

## Packages

All four releases use version 0.3.0 and follow the CSS version for subsequent releases:

- CSS, standalone with optional CSSX discovery.
- CSSX, installed inside CustomShellSystem, with its core under cores/.
- CSSX UI Kit, a separate technology-preview extension under extensions/.
- CSSX Cheat Menu, a separate native extension under extensions/.

Commit implementation changes by context, then bump versions together. Build and verify clean ZIPs with only required files. Exclude development cores, logs, user settings, saves and test output. Verify generated defaults on a fresh install. Retain existing CSS outfit compatibility and both measured game-build paths.
