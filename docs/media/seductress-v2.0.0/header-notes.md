# Seductress V2 banner

Generated on 14 September 2026 using the V1 `seductress-header.png` as the visual reference. This is promotional artwork, not a gameplay capture.

The brief retained the antique-gold frame, ruined stone backdrop, moth crest and masked character portrait, with the title `SEDUCTRESS V2`, the line `CUSTOM SHELL SYSTEM` and the credit `by _eins0fx`. All lettering, the border and both horn tips remain inside the composition.

- `seductress-v2-header.png`: complete generated image, 1983 × 793. Used in the description BBCode.
- `seductress-v2-header-1300x372.png`: Nexus header upload, RGBA, exactly 1300 × 372.

The upload export uses Pillow `ImageOps.contain` with LANCZOS resampling to fit the full design to 930 × 372, centered on a transparent 1300 × 372 canvas. The transparent side margins are 185 pixels each. No crop or stretching.

The existing `topless-harness-front.jpg` screenshot is referenced unchanged in the description. It was not used to generate the banner.
