[b]CSS 0.4.1[/b]

Three fixes to the COLOR tab that 0.4.0 introduced. If you are on 0.4.0, take this one.

[list]
[*][b]The colour swatches show up.[/b] Selecting a part opens a strip of colours to pick from; in 0.4.0 every chip in it was drawn with no colour, so the panel looked empty apart from the buttons.
[*][b]The tabs stay put.[/b] In 0.4.0, scrolling onto a colour part could make CSS and CSSX disappear from the inventory. The swatch grid pushed the page past a limit on how much CSS expected to find on one tab, and the check that caught it was strict enough to take the whole wardrobe down. That limit is raised and that check can no longer unload anything: at worst a panel now arrives without its slide-in.
[*][b]The colour grid no longer overlaps the buttons beneath it[/b], which had printed "Choose a colour" on top of "Exact color".
[*]A part your palette does not set now reads [b]Original[/b] rather than the palette's name. Palettes dress the outfit and leave your body alone, so Skin, Mask and Eyes were claiming to be "Midnight silver" while showing the author's own colour.
[/list]

[b]Only CSS needs updating.[/b] Nothing else changes from 0.4.0. Existing outfit and port ZIPs still work, your colours and saved looks are untouched, and CSSX, UI Kit and Cheat Menu remain at 0.3.0.

Close the game and extract the ZIP into [code]MortalShell2/Binaries/Win64/ue4ss/Mods/[/code]
Replace the CSS runtime files. Keep your [b]CustomShellSystem/state/[/b] folder, CSSX, extensions and installed outfits.
