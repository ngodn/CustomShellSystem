[b]Expected folders after extraction[/b]
Install CSSX first. Extract the [b]eins0fx.cheat-menu[/b] folder into [b]CSSX/extensions/[/b]. The extension files should be here:

[code]Sparta/MortalShell2/Binaries/Win64/ue4ss/Mods/CSSX/extensions/
`-- eins0fx.cheat-menu/
    |-- CREDITS.txt
    |-- LICENSE
    |-- README.txt
    |-- THIRD_PARTY_NOTICES.txt
    |-- assets/
    |   `-- banner-v1.png
    |-- cheat_menu.dll
    |-- extension.json
    `-- menu.json[/code]

Do not add another folder level around the extension. Its extension.json must be directly inside the folder shown.
