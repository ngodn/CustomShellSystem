CSS Eve (Stellar Blade), Black Pearl
Technology preview for CSS v1.0.0-alpha.1 by _eins0fx

Install
Close the game. Install CSS v1.0.0-alpha.1 and its required UE4SS build first.
Extract CSS_EveStellarBlade_eins0fx_P into MortalShell2/Content/Paks/~mods/.
Keep the .pak, .ucas and .utoc together. Remove an older Eve/SeduXtress
Black Pearl package before installing; do not leave duplicate versions mounted.
Keep your CSS state folder. Existing Black Pearl choices retain their identity.

Open Inventory > CSS > SHELL. Select Eve (Stellar Blade), Black Pearl.
Under LOCOMOTION choose Eve separately for Walk, Jog and Sprint. These are
opt-in. Default restores the game's movement. Feminine (CSS) supplies a standing
idle; a custom Eve idle and beacon teleport animation are not included yet.

Includes corrected walk/jog/sprint footing accepted in gameplay review,
modular clothing, five outfit palettes plus Original, independent color
swatches, body controls, secondary motion and accepted heel/ground alignment.
Original body proportions and the repaired hand rig are preserved.

This is a sample technology preview, not a completed modder kit or a promise
of perfect contact with every weapon and animation. Broad combat/transition
coverage remains incomplete. Keep CSSX disabled. Use normal game restarts
for updates; DLL hot reload is not supported by this release workflow.

Character/game reference: Eve from Stellar Blade. The package retains its
embedded model-source metadata. No Blender project or extracted source-game
animation library is distributed in this download.
