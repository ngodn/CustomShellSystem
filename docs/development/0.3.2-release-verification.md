# CSS 0.3.2 release verification

Only CSS is updated. CSSX, UI Kit and Cheat Menu remain at 0.3.0. The outfit
package format, saved-state schema and extension ABI are unchanged.

## Source and build

- Attachment correction: `ca71b6b`.
- Annotated tag: `v0.3.2`, source commit `e407131a7d06bdbeb391c7ecc48039854e9e54f9`.
- Clean detached checkout at that tag, pinned UE4SS SDK `d7e7826d`.
- Release Windows x64 loader and core built successfully with
  `CSS_INVENTORY_DEV=OFF` and `CSS_TRANSITION_TESTS=OFF`.
- 53 Python tests and all nine native test groups passed against tagged source.
  The first Python run lacked the local repak binary; linking the existing test
  tool into the ignored build directory resolved those failures. No source

## Runtime checks

Before packaging, the live Long Hair comparison failed on the old core and
passed with the correction. Tiel and Eredrim attachment bones, native draw/stow,
six alternating shell swaps, Original restoration and core-reload cleanup pass.
Three stock/empty-MID/active-effect recovery cycles and Inventory cleanup pass.
See [the attachment report](jayluk3-longhair-attachments.md) for evidence and limits.

The exact core extracted from the final ZIP was then loaded using the existing
verified permanent loader. It restored the currently selected Seductress outfit
on corrupted Genessa, with saved preferences byte-identical. The developer core
was restored afterward for continued investigation. This verifies release-core
activation and recovery, not a fresh game-process launch of the full ZIP. The
newly built loader has not been cold-started in-game.
