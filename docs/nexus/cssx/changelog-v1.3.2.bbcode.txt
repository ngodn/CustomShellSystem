[list]
[*]Extensions can live inside the game's Photo Mode. An extension that asks for it gets its own row on the pause menu's System page, right under Activate Photo Mode, and its pages as extra tabs in the Photo Mode panel, built from the game's own tabs and rows so they look and behave like the game's. The tab strip scrolls when the extra tabs don't fit. CINE 2.0.0 is the first to use it.[/*]
[*]Closing Photo Mode removes everything an extension added, so the game's own Activate Photo Mode always opens the panel exactly as it ships.[/*]
[*]An extension can step out of Photo Mode for a moment (to let you walk, or to run its own camera) and come back into it on one of its tabs.[/*]
[*]Extensions can read single rows from the game's data tables.[/*]
[/list]
