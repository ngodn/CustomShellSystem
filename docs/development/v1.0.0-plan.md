# CSS Next-Gen (v1.0.0-beta) Master Architecture & Engine Plan

> **Supersedes**: Legacy `v1.0.0-plan.md` (0.4.x outfit-replacement model).
> **Target Branch**: `v1.0.0-beta`
> **Platform Target**: Mortal Shell II (Unreal Engine 4.26+ / UE4SS Runtime Modding Framework).
> **Core Principle**: *Modders define whatever customization their pack exposes; Custom Shell System (CSS) provides the high-performance runtime engine, anatomical physics solvers, and the comprehensive UI Kit.*

---

## Executive Summary & System Philosophy

In previous iterations, CSS operated as a wardrobe swapper: packages provided full replacement character meshes with color dyeing and basic spring bone reflection.

**CSS Next-Gen (v1.0.0-beta)** transforms CSS into a **modular character engine and rich UI framework**. Mod authors provide the creative assets—meshes, materials, skeletons, morph banks, and physics configs—while CSS executes runtime physics simulation, multi-mesh deformation synchronization, collision detection, dynamic material management, and an interactive UI Kit.

## 1. Architectural Terminology: Profiles vs. Templates

To eliminate past ambiguities, CSS establishes strict, unambiguous definitions:

### 1.1 Profile (The Global Character Snapshot)
*The 4th main UI tab is officially renamed from `TEMPLATES` to **`PROFILE`** (or `PROFILES`).*
* **Definition**: A Profile is a complete serialization of the player's active character setup across **all tabs and systems**.
* **Contents**:
  1. **Shell & Modular Slots**: Equipped items across all slots (`body`, `hair`, `head`, `face`, `neck`, `chest`, `waist`, `legs`, `feet`, `hands`, `jewelry`, `genitalia`, `fabric`).
  2. **Anatomy & Morphs**: All active morph target weights (body proportions, breast size/shape, glute projection, facial features, genital morphs).
  3. **Customization & Materials**: Active dye colors, RGB overrides, group tints, roughness, opacity, metallic, and texture choices.
  4. **Physics & Dynamics**: Live spring bone frequencies, damping ratios, displacement clamps, and cloth settings.
  5. **Animation Stance**: Stance/walk style overrides.
* **Storage**: Saved as standalone JSON files (`.cssprofile`) in `Saved/CSS/Profiles/`. Fully exportable, importable, and shareable across the community.

### 1.2 Template (Modular Presets & Combinations)
*A **Template** is an authored or saved configuration within a specific subsystem. It does not overwrite unrelated systems.*
What constitutes a Customization Template?
1. **Combination / Style Templates**: Curated gear combinations (e.g., *"Topless Harness"* = Harness + Collar + Cuffs + Bare Chest Mesh + Stockings, accompanied by automatic section-hide rules).
2. **Palette Templates**: Coordinated color, material, and dye schemes (e.g., *Crimson Vow*, *Midnight Silver*, *Ash Gold*, *Ethereal Jade*).
3. **Body Archetype Templates**: Anatomic proportion presets (e.g., *Athletic Amazon*, *Petite Seductress*, *Voluptuous Matron*, *Battle-Hardened Heroine*).
4. **Physics & Dynamics Templates**: Secondary motion presets (e.g., *Natural Soft-Tissue*, *Firm Sports*, *Exaggerated Jiggle*, *Heavy Armored Dampening*).
5. **Hair & Grooming Templates**: Combined hairstyle, hair cards, beard/eyebrows, and pubic groom presets.
6. **Jewelry Set Templates**: Coordinated piercing and adornment loadouts (e.g., *Occult Silver Chains*, *Royal Gold Adornments*, *Minimalist Studs*).
7. **Glow & Rune FX Templates**: Emissive runes, breathing pulse rates, and hue patterns.

### 2.1 Interactive Components
1. **Searchable ComboBox / Fuzzy Picker ("Browse Modal")**:
   - For slots or properties with many options (e.g., 50+ hairstyles, 100+ morphs, extensive catalog items).
   - Instant text-filtering with fuzzy matching on keyboard input.
   - 8 items per page, smooth gamepad d-pad scrolling, mouse-wheel support, and preview thumbnail chips.
2. **Comprehensive Slider Suite**:
   - **Tint Sliders**: Hue (0° to 360° continuous dial), Saturation (0.0 to 2.0), Brightness/Value (0.0 to 3.0).
   - **Discrete RGB Sliders**: Individual Red, Green, Blue channel scalars for precision color tuning.
   - **Opacity & Transparency Sliders**: Alpha blend factor (0.0 to 1.0) with automatic translucent/dithered material mode selection.
   - **Physics Tuning Sliders**: Frequency (0.5 to 10.0 Hz), Damping Ratio (0.01 to 1.50), Travel Clamp / Max Displacement (0.0 to 20.0 cm).
   - **Morph Weight Sliders**: Normalized blendshape weights (0.0 to 1.0, or bidirectional -1.0 to +1.0) with real-time viewport updates.
   - **Glow & Emissive Sliders**: Luminance multiplier (0.0 to 50.0 cd/m²), Pulse Breathing Frequency (0.0 to 5.0 Hz).
3. **Color Swatches & Dynamic Palettes**:
   - 24-chip deterministic swatch strip (author defaults + palette samples + hue circle + brightness ramps).
   - Custom swatch storage: Save favorite colors directly into a persistent player palette.
4. **Modals & Confirmation Dialogs**:
   - Centered modal dialogs that trap focus and dim the underlying background.
   - Destructive confirmation: Overwriting a profile, clearing customized values, or resetting all overrides.
   - Text entry modal with on-screen virtual keyboard for gamepad users and direct text input for keyboard users.

## 3. The Custom CSS Runtime Engine

The CSS Engine operates inside the game process via native C++ and UE4SS reflection, controlling skeletal meshes, physics assets, dynamic materials, and animation graphs without requiring game editor recompilations.

### 3.1 Modular Mesh & Multi-Slot Attachment Engine
* Replaces the rigid single-mesh outfit model with a modular multi-slot follower hierarchy.
* **Core Slots**:
  - `body`: The base anatomy / skin mesh (e.g., Genesis 2 Female derived character mesh).
  - `head`: Head mesh, facial features, teeth, tongue, eyes.
  - `hair`: Head hair cards / groom strand rig.
  - `face`: Masks, blindfolds, glasses, facial piercings.
  - `ears`: Earrings, ear cuffs, elf ear extensions.
  - `neck`: Collars, chokers, necklaces, gorgets.
  - `chest`: Harnesses, brassieres, cuirasses, shirts, robes.
  - `back`: Capes, cloaks, quivers, wings, stowed large weapons.
  - `waist`: Belts, sashes, corsets, skirts, loincloths.
  - `hands`: Gloves, gauntlets, rings, fingernails/claws.
  - `legs`: Stockings, pants, greaves, garters.
  - `feet`: Boots, high heels, sandals, barefoot options.
  - `jewelry`: Piercings (nipple, navel, genital), body chains.
  - `genitalia`: Independent anatomical meshes (geografts), piercings, pubic groom.
* **Dynamic Follower Component Management**:
  - Follower meshes are attached via `AddComponentByClass(USkeletalMeshComponent)` and driven by `SetLeaderPoseComponent`.
  - **Priority Draw Order (`order`)**: Establishes render depth for overlapping geometry (e.g., skin = 0, stockings = 10, garter = 20, skirt = 30, coat = 40).
  - **Dynamic Section Masking (`hides_sections`)**: Worn items automatically hide specific material sections of underlying meshes (e.g., boots hide feet and ankles; tight corset hides midriff geometry), eliminating mesh poke-through with zero vertex overhead.

### 3.2 Spring Bone, Soft Bone & Secondary Physics Engine
* Live secondary motion simulation for soft body tissues, hair, breasts, glutes, fabrics, and accessories.
* **Harmonic Oscillator Solver**:
  $$\ddot{x} + 2\zeta\omega_n\dot{x} + \omega_n^2 x = F_{ext}$$
  - Modder parameters are declared as natural **Frequency ($f$ in Hz)** and **Damping Ratio ($\zeta$)**, automatically converted by CSS into UE `SpringStiffness` ($K = (2\pi f)^2$) and `SpringDamping` ($D = 4\pi\zeta f$).

#### The Four "Secret Ingredients" from Stellar Blade & Better Jiggle Mod v2.6.3:
1. **Rotational Angular Swinging (`bRotateX/Y/Z = true`)**:
   - Stock Unreal SpringBone is baked translate-only, causing bones to slide mechanically like pistons.
   - Enabling 3-axis rotation allows breasts and glutes to **sway, tilt with chest orientation, and circle with angular momentum**, producing organic, sensual softness.
2. **Travel Clamping as an Enabler of Low Damping (`MaxDisplacement` + `bLimitDisplacement = true`)**:
   - Setting a strict physical travel clamp (e.g. 1.5–6.0 cm for breasts, 2.5–8.0 cm for hips) eliminates explosive vertex flinging.
   - Because the clamp guarantees structural safety, **damping can be drastically lowered** ($D = 2.5 - 7.5$ instead of $20 - 50$), allowing genuine harmonic resonance, overshoot, and lingering soft-tissue ripples.
3. **Local-Space vs. World-Space Separation (`bUseLocalSpace`)**:
   - **Breasts (`bUseLocalSpace = true`)**: Breasts simulate relative to the ribcage so running or dodging moves them against the torso rather than lagging behind in world space.
   - **Hips / Glutes (`bUseLocalSpace = false` or hybrid + `AverageVelocityFrameCount = 3..4`)**: Simulating the pelvis with multi-frame velocity smoothing captures whole-body stride inertia, producing that hypnotic, rhythmic roll during locomotion.
4. **Axis-Selective Translation Constraints**:
   - **Thighs**: `bTranslateY = false`, `bTranslateX = true`, `bTranslateZ = true`. Eliminates lateral cross-thigh clipping while preserving vertical bounce and forward/backward roll.

#### Kawaii Physics Integration for Hair & Multi-Joint Chains:
* Integrated alongside SpringBone for long hair (ponytails, braids), skirts, and chains:
  - **Bone Length Invariance**: Enforces strict distance projection constraints so hair never stretches or collapses under high velocity.
  - **Bone Subdivision (`BoneSubdivisionCount`, `bBoneSubdivisionDensifyByRadius`)**: Inserts dummy collision bones between physical joints, creating an unbroken collision hull that prevents hair from clipping through the chest, neck, or shoulders.
  - **Damping Curves (`DampingCurveData`)**: High stiffness at scalp roots transitioning to fluid sway at the tips.
  - **In-Game Reflection**: Reflected live via `AnimGraphNode_KawaiiPhysics` with `bUpdatePhysicsSettingsInGame = true`.

### 3.3 Morph Target & Blendshape Deformation Engine
* Custom meshes cooked by modders carry morph targets. CSS drives them with synchronized, bidirectional deformation.
* **Cross-Mesh Morph Synchronization**:
  - When the player adjusts the `Breast_Size` or `Hips_Thicc` morph on the `body` slot, the CSS engine automatically propagates the identical morph weights to all currently equipped followers (harnesses, dresses, lingerie, stockings) carrying matching morph target names.
* **Bone-Center & Joint-Orientation Formulas (The VaM Formula Engine)**:
  - *Problem*: Changing mesh shape via morph targets expands the skin outward, but leaves bones, physics colliders, and socket attachments stationary inside the old volume.
  - *Solution*: Each morph definition can include a `formulas` list specifying joint translations and rotations:
    ```json
    {
      "morph": "Hips_Thicc",
      "weight": 1.0,
      "formulas": [
        {"target": "hip_l", "type": "BoneCenterX", "multiplier": 0.045},
        {"target": "hip_r", "type": "BoneCenterX", "multiplier": -0.045},
        {"target": "pelvis", "type": "BoneCenterY", "multiplier": 0.022}
      ]
    }
    ```
  - CSS dynamically shifts bone rest-transforms, ensuring sockets (e.g., stowed weapons, hip chains) and physics colliders remain locked to the new flesh boundary.

### 3.4 Specialized Anatomical Systems

#### A. Breast System
* **Dual-Layer Simulation**:
  - *Structural Layer*: Base pectoralis bone chain reacting to whole-body inertia and gait.
  - *Adipose Soft-Tissue Layer*: Apex spring bones (`brust_01_l/r`, `brust_02_l/r`) simulating soft tissue jiggle, lag, and rebound.
* **Anatomical Morphs**: Independent sliders for Volume, Sag/Gravity Droop, Cleavage Compression (push-up effect), Areola Size, and Nipple Projection.
* **Fabric Interaction**: When a tight bra or harness is equipped, the breast shape automatically applies a *Compression Morph* while reducing jiggle frequency to reflect tight fabric constraint.

#### B. Hips, Thighs & Glutes System
* **Gluteal Dynamic Solver**: Individual soft-tissue springs for `butt_01_l/r` with anisotropic damping (higher horizontal resistance, looser vertical bounce).
* **Thigh Stride Deformation**: Dual-quaternion twist distribution preventing volume collapse at extreme hip flexion during combat dodges.
* **Squish & Contact Deformers**: Ground/surface awareness that compresses gluteal geometry when sitting or crouching.

#### C. Genitalia & Orifice System
* **Fully Articulated Rigging & Morphs**:
  - Complete bone controls for labia minora, labia majora, clitoral hood, and perineum.
  - Morphs for anatomical variety, depth, spread, and tone.
* **Dynamic Orifice Engine**:
  - **3D Penetration Alignment Curve**: Procedural spline curve defining orifice entry and canal trajectories for vaginal, anal, and oral cavities.
  - **Proximity & Collision Deformers**: When an external collider (finger, weapon, prop, penetrator) enters the proximity threshold, the orifice triggers automated dilation, bulge, and stretch morphs along the penetration depth axis.
* **Dynamic Wetness & Specular Layer**:
  - Dedicated material parameter channel driving roughness (down to 0.05), specular (up to 1.0), and normal glossiness maps simulating fluid lubrication.

### 3.5 Hair & Grooming System
* **Head Hair**:
  - Hybrid card/strand skeletal hierarchy with spring bone chains.
  - Multi-point collision capsules against head, shoulders, and chest to prevent hair from falling into the torso.
  - Wind velocity and locomotion momentum coupling.
* **Head Accessories**:
  - Horns, tiaras, veils, ribbons, and headbands socketed to skull bones with optional dangle physics.
* **Genitalia & Body Hair**:
  - Conforming hair-card geografts for pubic groom with adjustable density, length, and color matching.
  - Underarm and brow grooming presets.

---

### 3.6 Fabric & Cloth System
* **Dynamic Cloth Integration**:
  - Supports Unreal Chaos Cloth profiles on skirts, capes, sashes, and robes.
  - For lightweight or stylized garments, supports Soft Bone chain simulation with wind reaction.
* **Anti-Clipping & Body-Conforming Engine**:
  - *Push Modifiers*: Procedural vertex offset along surface normals to prevent tight straps and harnesses from cutting into flesh.
  - *Alpha Cutout Masks*: Material-level opacity masks that clip out unseen character body geometry under skin-tight clothing.

---

### 3.7 Jewelry & Hard Surface Accessories
* **Socket & Skin-Vertex Anchoring**:
  - Rigid pieces (rings, earrings, studs) attach to standard bone sockets.
  - Piercings (nipples, navel, labia) and skin adornments use **Barycentric Skin Vertex Linking**, keeping the jewelry anchored to skin vertices regardless of morph target expansion or soft-tissue jiggle.
* **Secondary Inertia & Sound**:
  - Dangling chains and pendants possess micro-spring physics and trigger subtle metal-clink audio effects during movement.

---

### 3.8 Universal Glow & Emissive Engine
* **Universal Glowable Component**:
  - Any visual element—eyes, skin runes, tattoos, fabric seams, gemstone jewelry, weapon blades, or fluids—can be declared as a glowable channel by the mod author.
* **Parameter Bus**:
  - `glow_color`: Vector RGB color tint.
  - `glow_intensity`: Scalar luminance (from subtle moonlight glow to blinding arcane radiance).
  - `glow_pulse_rate`: Frequency in Hz for breathing/pulsing luminescence.
  - `glow_mask`: Texture channel mask isolating rune patterns or gemstone facets.
  - `glow_combat_reactive`: Dynamic hook amplifying glow intensity during stamina drain, weapon strikes, or parries.
