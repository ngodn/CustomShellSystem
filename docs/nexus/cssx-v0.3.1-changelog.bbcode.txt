[b]CSSX 0.3.1[/b]

Major update for Custom Shell System Extensions (CSSX), introducing the ABI 2 retained HUD surface architecture, native minimap/marker provider integration, and library presentation improvements.

[size=4][b]Features & Architecture[/b][/size]
[list]
[*][b]CSSX ABI 2 Retained HUD Surface:[/b] Adds a retained HUD surface to the game player HUD. Native C++ extensions can create and update canvas layers, textures, compass tapes, and radar widgets.
[*][b]Cached Layer Updates:[/b] The retained layer pipeline caches layer handles and skips redundant Slate property updates (translation, scale, angle, opacity, visibility) when those values have not changed between frames.
[*][b]Native Minimap & Marker Provider Hooks:[/b] Built-in integration for native minimap configuration and world-marker tracking (Lost Gloom recovery points, nearby dungeons, and player map pings with real-time distance calculations).
[*][b]Extension Library Card Banner Scaling:[/b] 3:1 card banners and circular emblems now maintain proper geometric proportions without stretching on wide (16:9, 16:10) and ultrawide (21:9, 32:9) monitors.
[*][b]Square Icon Protection:[/b] Extensions using square icons instead of panoramic banners are now centered cleanly as square badges without horizontal distortion across the 3x3 card grid.
[*][b]Clean Transparent Logo Compositing:[/b] Resolved background fill artifacts behind the CSSX top header logo, ensuring seamless transparency over the dark inventory canvas.
[/list]

[size=4][b]Installation[/b][/size]
Requires CSS 0.4.2 or later. Close the game and extract the ZIP [b]inside CustomShellSystem/[/b], merging its [b]assets/[/b] and [b]cores/[/b] folders:
[code]Sparta/MortalShell2/Binaries/Win64/ue4ss/Mods/CustomShellSystem/
|-- core.json
|-- cores/
|   |-- css_core-0.4.2.dll
|   `-- cssx_core-0.3.1.dll
|-- cssx.json
`-- extensions/
    |-- eins0fx.cheat-menu/
    |-- eins0fx.compass-minimap/
    `-- cssx.ui-kit/[/code]
