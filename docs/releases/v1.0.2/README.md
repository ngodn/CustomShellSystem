# CSS 1.0.2 coordinated delivery

The release contains CSS 1.0.2, CSS Shared Assets 1.0.2 and full updates for the
affected outfits. Each product follows its own version sequence. Shader repairs
are part of the outfit update, never a replacement product name. CSSX 1.3.1 and
Traverse 1.0.2 have no code changes for this update and retain their versions.

The source for each BBCode changelog is in this directory. Delivery copies sit
beside their ZIPs under `dist`. `dist/DELIVERY.md` is the current download index.
