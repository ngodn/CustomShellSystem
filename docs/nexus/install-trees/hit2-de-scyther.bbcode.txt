Install CSS and UE4SS first. Extract the [b]CSS_HIT2_DE_Scyther_XTGMods_P[/b] folder into [b]MortalShell2/Content/Paks/~mods/[/b].

[code]Sparta/MortalShell2/Content/Paks/~mods/
`-- CSS_HIT2_DE_Scyther_XTGMods_P/
    |-- CSS_HIT2_DE_Scyther_XTGMods_P.pak
    |-- CSS_HIT2_DE_Scyther_XTGMods_P.ucas
    `-- CSS_HIT2_DE_Scyther_XTGMods_P.utoc[/code]

Keep all three files together and preserve their _P filenames. Restart the game, then select the outfit in Inventory > CSS. Outfit packages go in ~mods, not UE4SS Mods or CSSX extensions.
