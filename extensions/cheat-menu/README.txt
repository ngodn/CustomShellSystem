CSSX Cheat Menu v1.1.2

Requires CSSX v1.3.1 for number entry (Mods/CSSX). Close the game, then extract the
eins0fx.cheat-menu folder into MortalShell2/Binaries/Win64/ue4ss/Mods/CSSX/extensions/.
Disable or remove the original MortalShell2Mod Lua menu first, then start the
game, load into the world and press F6 (or open the Player Menu and switch to
the CSSX tab) > CSSX Cheat Menu.

Type numbers in the value field and press Enter or click Set value. Escape
cancels the entry. Controller arrows also adjust numbers. Amounts and target
levels are ready immediately; then choose the action you want to run.
Toggles and settings for running cheats need Settings > Apply settings.
Cheats start off at every launch. Actions marked "Persists in your save" or "Irreversible"
change your save file and are not undone by turning cheats off or removing
this extension. "Turn off all cheats" restores every value the menu owns and
leaves newer changes made by the game or another mod alone.

Your settings live in Mods/CSSX/state/eins0fx.cheat-menu.json; logs in
Mods/CSSX/logs/eins0fx.cheat-menu/.
