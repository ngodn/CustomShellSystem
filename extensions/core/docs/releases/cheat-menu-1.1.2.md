# CSSX Cheat Menu 1.1.2

### Changed

- Type amounts, levels, percentages and speed settings instead of dragging
  sliders or repeatedly pressing arrows.
- Shorten the instructions for numeric settings.

### Fixed

- Resource and item quantities no longer tell you to use Apply settings.
  Set the quantity, then choose the action. Running cheat settings still need Apply.

### Upgrading

Install CSSX 1.3.1 for number entry. Close the game and extract this update into
`ue4ss/Mods/CSSX/extensions/`. Keep your saved settings in `CSSX/state/`.
