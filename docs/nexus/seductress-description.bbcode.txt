I adapted Skirbie's Baldur's Gate 3 Seductress outfit for Mortal Shell II and the CSS wardrobe, with a fitted body, flowing skirt, ornate metalwork and a Genessa-inspired headpiece. Choose the original colors, use one of four palettes or customize individual parts.

[b]This download contains the Seductress outfit. Install Custom Shell System and UE4SS separately.[/b] Wearing it keeps your current shell's abilities.

[size=4][b]Customization[/b][/size]
[list]
[*]Original colors, plus Crimson vow, Ash and gold, Midnight silver and Verdigris.
[*]Separate color controls for Garment, Ornaments, Skin, Mask and Eyes.
[*]Adjustable eye glow intensity.
[*]An authored dewy skin finish.
[*]Support for CSS favorites and saved looks.
[/list]

Select [b]Seductress[/b], then open the [b]Color[/b] tab. Choose Original or Reset all colors to restore the outfit's original materials. This package has one mesh variant. Body shape, skin wetness and physics strength are not adjustable sliders.

[img]https://raw.githubusercontent.com/ngodn/CustomShellSystem/main/docs/media/v0.2.0/inventory-css.jpg[/img]

[size=4][b]Requirements and installation[/b][/size]
[list=1]
[*]Close the game.
[*]Install [url=https://www.nexusmods.com/mortalshell2/mods/45?tab=files]UE4SS for MS2 by Framecore[/url] and [url=https://github.com/ngodn/CustomShellSystem/releases/tag/v0.2.0]Custom Shell System[/url]. CSS 0.2.0 adds the native Inventory menu and keeps this outfit package compatible.
[*]Extract CSS_Seductress_eins0fx_P.zip and copy the included CSS_Seductress_eins0fx_P folder into Sparta/MortalShell2/Content/Paks/~mods/.
[*]Enter the game world, open [b]Inventory[/b] (default [b]I[/b]) and select [b]CSS[/b]. In Shell, select Seductress and choose Wear.
[/list]

[code]Sparta/MortalShell2/Content/Paks/~mods/CSS_Seductress_eins0fx_P/
    CSS_Seductress_eins0fx_P.pak
    CSS_Seductress_eins0fx_P.utoc
    CSS_Seductress_eins0fx_P.ucas[/code]

Keep all three files together and preserve their _P suffixes. The thumbnail, metadata and color resources are inside the package. You do not need BG3, the original BG3 download or the BeauteGenessa replacement installed.

[size=4][b]Compatibility and known issues[/b][/size]

I fitted and tested Seductress with Genessa's human skeleton. CSS checks skeleton compatibility before applying an appearance; I have not tested every gameplay shell. Other CSS outfits can stay installed. Regular replacements that overwrite the game's original Genessa meshes or materials may affect this outfit.

[list]
[*]The feet can appear slightly above the ground in the 1.0.0 package. The prepared alignment revision is not included in this download.
[*]CSS 0.2.0 uses the game's Inventory preview and lighting. Older CSS screenshots show the retired standalone wardrobe.
[*]Cloth and secondary motion use the existing game/mod animation setup. They are not a separate physics engine, and some animations may still clip.
[/list]

If something breaks, please include the Seductress version, CSS version, active gameplay shell and steps to reproduce it. A screenshot or short recording helps me find the cause.

[size=4][b]Updating or removing[/b][/size]

Close the game before replacing the package files, and keep only one installed copy of Seductress. Your colors and saved looks are stored by CSS.

To remove it, select Original appearance in CSS, close the game and delete CSS_Seductress_eins0fx_P from ~mods. Keep CSS if you use other wardrobe outfits.

[size=4][b]For modders[/b][/size]

The [url=https://github.com/ngodn/CustomShellSystem]CSS source[/url] and [url=https://github.com/ngodn/CustomShellSystem/blob/main/tools/css_convert.py]converter[/url] are on GitHub. The converter packages compatible cooked Mortal Shell II mods; it does not perform the cross-game fitting used for Seductress. Materials, weights, dependencies and color masks may need individual work. See the [url=https://github.com/ngodn/CustomShellSystem/blob/main/docs/modding/README.md]CSS modding guide[/url] for the current asset requirements, packaging tools, variants and color recipes. I'll update it as the framework develops.
