CSS + Eve (Stellar Blade), Black Pearl
Playable checkpoint, 21 September 2026

This is the tested development checkpoint currently installed in the author's
game. It is not the completed CSS v1.0.0 release. The Eve package retains its
1.0.0-candidate version; CSS remains on the 0.4.2 development line.

Included
- Eve (Stellar Blade), Black Pearl, with the accepted body proportions,
  repaired hand rig, heel supports and visual ground offset.
- Hair and body motion controls, modular outfit parts, color swatches and
  five additional outfit palettes.
- CSS lighting controls, favorites, official-shell visual appearances,
  scrollable choices and contextual button hints.
- The exact tested CSS development core and its matching loader.

Requirements
Mortal Shell II (Unreal Engine 5.6.1).
UE4SS for MS2 NO AOB, v3.0.1-1111-g97b7e501, GameShippingWin64.
Get the compatible build from:
https://www.nexusmods.com/mortalshell2/mods/45?tab=files
Expected UE4SS.dll SHA-256:
fb1839ee91f71f83d508d44a2763a15ac1bb0c5fb4e504ac0fcfca64376a054a
UE4SS itself is not included.

Install or restore this checkpoint
1. Close Mortal Shell II normally.
2. Back up your existing CustomShellSystem folder and Black Pearl package.
3. Extract the Binaries and Content folders into the MortalShell2 folder,
   merging folders and replacing the matching files.
4. Remove an older copy of this same Black Pearl outfit if it is installed
   under its former SeduXtress name. Keep unrelated outfit mods.
5. Leave CSSX disabled for this checkpoint. This ZIP does not install or
   disable other extensions on your behalf.
6. Start the game, enter the world, open Inventory > CSS, and select
   Eve (Stellar Blade) > Black Pearl.

Your current installation already contains this tested baseline. Reinstalling
this ZIP is optional. No restart or installation was performed to make it.

Keep your existing CustomShellSystem/state folder. This archive contains no
state, favorites, profiles, game saves, logs, cached assets or probe requests.
It preserves the existing outfit identity used by saved looks.

Preview controls
Y on controller, or I on keyboard: toggle Lighting controls.
Select/View: favorite the selected outfit. B/Esc: Back or Close.
Follow the on-screen hints for browsing and editing the current selection.
View mode: right mouse drag rotates, mouse wheel zooms, left drag moves.
Lighting mode locks the preview view and repurposes the preview controls.

What remains unfinished
Custom Eve idle, walk, jog, sprint and beacon animations are not included.
The separate motion preview shows offline experiments, not installed motion.
The new Default label and expanded animation selectors are in newer source
work and are not part of this older tested binary.
Broader combat, lifecycle and performance coverage, the final v1.0.0 release,
and the complete modder kit/tutorial remain in progress.

Development build
This checkpoint retains development diagnostic hooks from the tested core.
It contains no diagnostic request files and is intended as a playable review
and recovery package, not a newly certified public shipping release.
Use a normal game restart for updates. DLL hot reload previously crashed an
animation worker during this project.
