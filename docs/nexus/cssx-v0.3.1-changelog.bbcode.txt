[b]CSSX 0.3.1[/b]

Major update for Custom Shell System Extensions (CSSX), introducing the ABI 2 retained HUD surface architecture, native minimap/marker provider integration, and library presentation improvements.

[size=4][b]Features & Architecture[/b][/size]
[list]
[*][b]CSSX ABI 2 Retained HUD Surface:[/b] Adds a hardware-accelerated retained HUD surface injected directly into [code]WBP_Player_HUD[/code]. Native C++ extensions can instantiate and update canvas layers, textures, compass tapes, and radar widgets with zero frame-rate overhead.
[*][b]Zero-Allocation Per-Frame Updates:[/b] The retained layer pipeline caches layer handles and skips redundant Slate property updates (translation, scale, angle, opacity, visibility) if values have not changed between frames. Zero heap allocations on the game thread tick path.
[*][b]Native Minimap & Marker Provider Hooks:[/b] Built-in integration for [code]SpartaMapWidget[/code] minimap configuration and world-marker tracking (Lost Gloom recovery points, nearby dungeons, and player map pings with real-time distance calculations).
[*][b]Extension Library Card Banner Scaling:[/b] 3:1 card banners and circular emblems now maintain proper geometric proportions without stretching on wide (16:9, 16:10) and ultrawide (21:9, 32:9) monitors.
[*][b]Square Icon Protection:[/b] Extensions using square icons instead of panoramic banners are now centered cleanly as square badges without horizontal distortion across the 3x3 card grid.
[*][b]Clean Transparent Logo Compositing:[/b] Resolved background fill artifacts behind the CSSX top header logo, ensuring seamless transparency over the dark inventory canvas.
[/list]

[size=4][b]Installation[/b][/size]
Requires CSS 0.4.2 or later. Close the game and extract the ZIP [b]inside CustomShellSystem/[/b], merging its [code]assets/[/code] and [code]cores/[/code] folders:
[code]Sparta/MortalShell2/Binaries/Win64/ue4ss/Mods/CustomShellSystem/
|-- core.json
|-- cores/
|   |-- css_core-0.4.2.dll
|   `-- cssx_core-0.3.1.dll
|-- cssx.json
`-- extensions/
    |-- eins0fx.cheat-menu/
    |-- eins0fx.compass-minimap/
    `-- cssx.ui-kit/[/code]
