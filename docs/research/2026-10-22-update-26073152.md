## Repair method and checks

`tools/ShaderDependencyAudit` uses .NET 10 and the retained patched CUE4Parse
revision `bbb3551af4c0c1bf481bc2821a18bd3b72706ff4`. It inspects export classes
for every package in the list, then reads material resources and checks shared
hashes and shader-group chunks. Inline code is parsed, not executed.

`tools/repair_shared_material_shaders.py` uses Python 3.14. The original mode
reconstructs both supplied Eve donor files byte for byte and checks unchanged
non-shader fields. The current-game mode extracts complete shader suffixes with
a serializer, then verifies their resources against independent AssetReadback
output. Native donor parents, static switches, base overrides and permutation
flags must match. The replacement preserves property bytes and changes only the
shader suffix and two serialized size/offset fields in canonical retoc output.

For a material whose saved switches differ from its existing cooked behavior,
an explicit compiled-reference input is required. Its full old shader data must
match a reference with the native donor's properties. Both decoded resources and
raw bytes are compared, allowing only the 20-byte cooked material identity hashes
to differ. Parents, base overrides and permutation flags must still match. Several
native donors with equivalent compiled output may differ only in identity hashes;
different bytecode or resource bindings are rejected. This preserves existing
compiled behavior instead of inventing a new permutation from dormant metadata.

HIT2's archived materials pass that explicit proof. The two top materials differ
from Genessa's old top shader only in identity hashes; hair matches the original
hair shader exactly. The ordinary static-property check rejected these materials
before that proof was supplied. Fixture checks reject truncated payloads, altered
shader bytes, incompatible decoded maps and unexpected headers.

Every packed candidate passes `retoc verify`, independent material readback with
all non-shader fields unchanged, and full-package shader dependency checks against
the updated game. Evidence includes `26073152-summary.json`,
`genessa-complete-verification.json`, `hit2-complete-verification.json`,
`cw-verification.json`, both `CSS_Seductress*-verification.json` reports,
`transplant-checks.json` and `compiled-reference-checks.json`.
