Install CSSX separately if you want extension menus. Remove or disable the original MortalShell2Mod and restart before using CSSX Cheat Menu.

Outfit attachment bones, some outfit-specific cloth/foot alignment issues and reported dodge-shadow or HIT2 projectile alignment issues remain under investigation. See the release notes for current limits.
